# 커밋 컨벤션

커밋 메시지는 반드시 아래 형식을 따른다.

**형식**: `<prefix>: <메시지>`

| Prefix | 설명 |
|--------|------|
| `feat` | 새로운 기능 추가 |
| `fix` | 버그 수정 |
| `docs` | 문서 수정 |
| `style` | 코드 포맷 변경 (코드 수정이 없는 경우) |
| `modify` | 기존 코드의 기능을 추가하거나 변경 |
| `refactor` | 중복 코드 제거, 변수명 변경, 가독성 향상 등 기존 코드 개선 |
| `test` | 테스트 코드 추가 |
| `chore` | 빌드 업무 수정, 패키지 매니저 수정 |
| `remove` | 파일 및 코드 삭제 |
| `rename` | 파일 및 코드명 변경 |

- 메시지는 한글로 작성한다.
- 예: `feat: 로그인 페이지 추가`, `fix: 검색 필터 초기화 버그 수정`
