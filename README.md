# Dewdew Portfolio

소프트웨어 엔지니어 이연주의 개인 포트폴리오 웹사이트입니다.  
현대적인 웹 기술과 사용자 경험을 중시한 풀스택 개발자의 작품집입니다.

**서비스 URL**: [https://www.dewdew.dev](https://www.dewdew.dev)

## 주요 기능

| 기능 | 설명 |
|------|------|
| 메인 페이지 | 실시간 날씨, 타이핑 애니메이션, 인트로 효과 |
| AI 채팅 (`/ai`) | RAG 기반 포트폴리오 AI 채팅 — 경력·프로젝트·스킬 질의 응답 |
| 다국어 지원 | 한국어/영어 실시간 전환 |
| 다크/라이트 모드 | 시스템 테마 자동 감지 및 사용자 선택 저장 |
| PWA | 오프라인 지원, 모바일/데스크톱 설치 가능 |
| 반응형 디자인 | 모든 디바이스 최적화 |
